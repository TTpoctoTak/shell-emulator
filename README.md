# Эмулятор командной оболочки

Учебный проект эмулятора командной оболочки UNIX-подобной операционной
системы. Программа реализована на Python с использованием графического
интерфейса Tkinter.

## Этап 1 — REPL

На первом этапе реализован минимальный прототип эмулятора, позволяющий
вводить команды через графический интерфейс и получать результат их
обработки.

### Реализованная функциональность

- графический интерфейс на Tkinter;
- отображение имени VFS в заголовке окна;
- ввод команд и их обработка по нажатию Enter;
- разбор введенной команды на имя и аргументы;
- раскрытие переменных окружения реальной операционной системы;
- команда-заглушка `ls`;
- команда-заглушка `cd`;
- команда `exit` для завершения работы;
- обработка неизвестных команд;
- проверка аргументов команд.

Команды `ls` и `cd` на первом этапе являются заглушками и не выполняют
реальных операций с файловой системой.

## Требования

Для запуска необходим Python 3.13 или новее с поддержкой Tkinter.

Дополнительные библиотеки Python не требуются.

## Запуск программы

Запуск через `run.bat` из корневой директории проекта:

```powershell
.\run.bat
```

Также программу можно запустить напрямую:

```powershell
python src/main.py
```

## Запуск тестов

Для запуска автоматических тестов из корневой директории проекта:

```powershell
python -m unittest discover -s tests
```

## Примеры использования

Команда `ls` без аргументов:

```text
> ls
ls: []
```

Команда `ls` с аргументом:

```text
> ls folder
ls: ['folder']
```

Команда `cd`:

```text
> cd documents
cd: ['documents']
```

При неверном количестве аргументов выводится сообщение об ошибке:

```text
> cd
Error: cd requires exactly one argument
```

При вводе неизвестной команды также выводится сообщение об ошибке:

```text
> unknown
Error: unknown command: unknown
```

Команда завершения работы:

```text
> exit
```

Поддерживается раскрытие переменных окружения реальной операционной
системы. Например:

```text
> ls $TEMP
```

Перед выполнением команды значение `$TEMP` будет заменено значением
соответствующей переменной окружения.
